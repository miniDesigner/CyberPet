# CyberPet IAA 商业化设计方案

> **版本**：v0.1（草案）　**日期**：2026-11-26　**状态**：待评审
> **关联文档**：[游戏设计文档](./游戏设计文档.md)（v0.8）
> **定位**：以 IAA（In-App Advertising，应用内广告）为主要运营方式，广告深度融入养成情感体验，而非打断玩法。

---

## 1. 设计前提与红线

本作的 GDD 已确立几条硬约束，广告设计必须在其框架内运作，不得破坏：

| 既有设定 | 对广告的约束 |
|---|---|
| 无金币、无付费、照顾全免费 | 广告**不引入任何货币**，不做「看片得金币」；兑换走「看片解锁/领取」的一次性权益 |
| 孵化 3/4/5 天、寿命 70–120 天不可加速 | 广告**不得加速孵化、缩短寿命、跳过成长阶段** |
| 死亡与产后 24h 护理是核心紧张窗口 | 广告**不得复活、免死亡、免产后死亡判定**，否则摧毁玩法内核 |
| 属性照顾免费无上限 | 广告**不做属性直接补满**，不制造数值碾压 |
| 拟真史前 + 手绘质感 | 广告入口视觉自然融入，不出现赛博/像素风，不遮挡主宠 |

**一句话原则**：广告只卖「外观、纪念、收集、便利」，绝不卖「生存优势」。

---

## 2. 广告形式选型

依据微信小游戏广告生态（激励视频 eCPM 约 50–200 元、完播率 60%+；插屏中高；Banner 约 5–20 元）与本作养成节奏，确定形式组合：

| 形式 | 定位 | 收入角色 | 用户体验 | 落地决策 |
|---|---|---|---|---|
| **激励视频** | 主力 | eCPM 最高，核心收入来源 | 用户主动选择、看完领奖，接受度最高 | **重点做**，绑定情感节点与福利站 |
| **插屏** | 辅助 | 中高 eCPM | 被动弹出，易打断 | **严格限量**，仅段落切换处，新用户保护 |
| **Banner** | 兜底 | 单价最低 | 常驻占位 | **仅福利站底部**，主界面绝不放 |
| 视频号 CPS / 激励 | 运营增益 | 平台激励加热金 | 不影响游戏内 | 阶段六评估接入，见第 9 章 |

> 结论：收入结构以激励视频为绝对主力，插屏与 Banner 只做补充，避免「广告过多 → 留存下滑 → 收入反而下降」的负循环。

## 3. 广告店（福利站）设计

### 3.1 定位与入口

- **名称**：福利站（不使用「商店」，因无货币）。
- **入口**：主界面次级入口，与「记录 / 图鉴」同排，成体阶段解锁（避免新用户一进来就被广告引导）。
- **页面结构**：四个分类标签 + 奖励卡片列表 + 底部 Banner 位 + 顶部「今日观看次数」计数。
- **核心体验**：玩家主动来、主动看、看完即得，全程无强制。

### 3.2 四类商品

| 分类 | 商品 | 性质 | 领取规则 | 平衡影响 |
|---|---|---|---|---|
| **每日福利** | 每日补给包（图鉴碎片 ×1） | 收集 | 每日 1 次 | 无，仅加速图鉴收集 |
| **外观装扮** | 相册相框（丛林/水域/草原） | 纯外观 | 一次性解锁 | 无，不作用于宠物数值 |
| 外观装扮 | 栖息地背景主题 | 纯外观 | 一次性解锁 | 无 |
| 外观装扮 | 宠物小配饰（不含能力） | 纯外观 | 一次性解锁 | 无，拟真风格内克制设计 |
| **纪念增强** | 成长纪念影片（一生回顾） | 情感 | 每次死亡/死亡后可生成 | 无，强化豢养记录情感价值 |
| 纪念增强 | 定制告别纪念卡 | 情感 | 死亡告别页可选 | 无，含蓄无血腥 |
| 纪念增强 | 传承纪念影片 | 情感 | 后代继承时可选 | 无 |
| **图鉴收集** | 稀有蛋纹理外观（不改变种类辨识） | 收集/外观 | 一次性解锁 | 无，不得干扰三蛋辨种 |
| 图鉴收集 | 混种图鉴条目补充 | 收集 | 碎片累计兑换 | 无 |

> **严格禁止的商品**：复活/免死亡、加速孵化/寿命、跳过产后虚弱、属性补满、影响三蛋颜色纹理映射的伪装外观、任何形式的货币。

### 3.3 兑换机制

- 「看片领取 / 看片解锁 / 看片生成」按钮标注清晰，点击前明确告知奖励内容。
- 看完激励视频后由服务端/本地标记发放，**不发货币、不产生可交易资源**。
- 每日次数上限记录在存档 `meta.adDaily`（见第 8 章），跨日重置。
- **例外**：挑蛋刷新不限次数（2026-11-26 评审决策，追求转化与挑蛋参与感），但仍计入 `meta.adDaily.watched` / `refreshed` 埋点。
- 解锁类权益永久保留；每日类当日有效。

## 4. 广告点位设计

### 4.1 激励视频点位（主动、情感高点）

| 点位 | 触发时机 | 奖励 | 设计意图 |
|---|---|---|---|
| 破壳揭晓 | 点击破壳、种类性别揭晓后 | 免费生成纪念卡 | 情感峰值，转化最高且不伤平衡 |
| 死亡告别 | 告别页 | 定制告别纪念卡 | 把「失去」转化为「留存纪念」，缓解挫败 |
| 后代继承 | 继承完成页 | 传承纪念影片 | 血脉延续的正向情绪节点 |
| 福利站 | 玩家主动进入 | 装扮/碎片/便利 | 常驻自主变现入口 |
| 繁育成功 | 孕期开始、产蛋后 | 孕期/产后纪念留影增强 | 仅纪念，不减免 24h 护理 |
| **挑蛋刷新**（已落地） | 三枚待选阶段点「看广告换一批」 | 重抽三枚蛋（全新一批） | 玩家主动想要更好选择，转化自然；**看完才刷新、不限次数**；种类可重复，不影响平衡 |

> 关键：所有激励点位都提供**「不看也能继续」**的等价基础路径（如默认纪念卡），广告只做增强，不做通关门槛。
> 挑蛋刷新是阶段二 Demo 首个落地的广告点位：领养改为随机重抽三枚（种类可重复），看广告可无限换一批，中途关闭不刷新（详见 GDD v0.9 第 3.2 节）。

### 4.2 插屏点位（被动、严格限量）

| 规则 | 值 |
|---|---|
| 触发点 | 从相册/图鉴/福利站返回主界面时 |
| 新用户保护 | 安装后前 3 天不弹插屏 |
| 每日上限 | ≤ 2 次 |
| 最小间隔 | ≥ 15 分钟 |
| 禁止位置 | 破壳、死亡、产后护理判定、繁育结算等关键动画中/后不弹 |

### 4.3 Banner 点位

- 仅福利站页面底部常驻；主界面、宠物照顾界面、弹层一律不出现。
- 不追求收入，仅作低门槛兜底曝光。

## 5. 频次控制与体验保护

| 项 | 上限 | 说明 |
|---|---|---|
| 激励视频 | 每日 ≤ 8 次 | 防止过度诱导，保护长期留存 |
| 插屏 | 每日 ≤ 2 次、间隔 ≥ 15 分钟 | 新用户前 3 天豁免 |
| Banner | 仅福利站常驻 | 主界面零广告 |
| 关键节点 | 破壳/死亡/产后/繁育结算后免插屏 | 避免情绪被打断 |
| 跳过能力 | 所有广告可跳过/关闭 | 激励视频未看完不发奖，符合平台规范 |

## 6. 数据与指标

### 6.1 核心指标（ funnel 拆解）

`广告收入 = DAU × 广告渗透率 × 人均展示次数 × eCPM`

| 指标 | 口径 | 目标（Demo 后首版） |
|---|---|---|
| 广告渗透率 | 当日看广告用户 / DAU | 30–40% |
| 人均激励视频次数 | 看广告用户人均 | 2–4 次/日 |
| eCPM（激励视频） | 千次曝光收入 | 50–120 元 |
| 插屏占比 | 插屏收入 / 总收入 | < 20% |
| 留存影响 | 看广告 vs 不看广告用户次留差 | 差值不显著为负 |

### 6.2 埋点

- `ad_impression`（形式/点位）、`ad_complete`、`ad_reward_granted`、`ad_skipped`。
- 关键点位（破壳/死亡/继承）单独打点，评估转化与留存关系。
- 频次与上限触达埋点，用于调优上限值。

## 7. 合规与审核风险

| 等级 | 风险 | 对策 |
|---|---|---|
| 🔴 高 | 诱导分享/诱导看广告被拒审 | 广告完全自愿，不做「不看完不能继续」，不做分享换广告 |
| 🔴 高 | 用广告 bypass 死亡/护理触碰玩法红线与审核 | 严守第 1 章红线，复活/免罚类商品一律不做 |
| 🔴 高 | 未成年人不适配广告内容 | 遵循平台未成年保护与广告内容规范，接入平台默认过滤 |
| 🟡 中 | 广告打断情感演出引发差评 | 关键动画后不弹插屏；激励点位提供「不看也能继续」路径 |
| 🟡 中 | 未达流量主门槛 | 需累计 UV ≥ 500 方可申请开通（见第 9 章） |
| 🟢 低 | 广告素材与拟真画风冲突 | 广告为平台素材不可控，仅在自有入口/相框上保持风格统一 |

## 8. 存档与技术实现

### 8.1 存档扩展（在 GDD v0.8 结构基础上）

```json
{
  "meta": {
    "adDaily": { "date": "2026-11-26", "rewardedCount": 2, "interstitialCount": 0, "lastInterstitialAt": 0 },
    "unlockables": { "albumFrames": ["jungle"], "habitats": [], "charms": [], "egg skins": [] },
    "installFirstDay": "2026-11-26"
  }
}
```

- `adDaily` 跨日按 `date` 重置；`installFirstDay` 用于新用户 3 天插屏保护。
- `unlockables` 存永久外观/纪念权益，不含任何货币或数值加成。

### 8.2 平台适配

- 微信小游戏用 `wx.createRewardedVideoAd`、`wx.createInterstitialAd`、`wx.createBannerAd`。
- 复用现有 `src/platform.js` 适配层：小游戏走 wx API，浏览器预览走 mock（不实际播广告，仅打日志与发奖），保证 Demo 可验证。
- 激励视频需在 `onClose` 回调中判断 `isEnded` 再发奖，未看完不发。

### 8.3 落地阶段

| 阶段 | 内容 |
|---|---|
| 阶段四（微信对接） | 接入激励视频 SDK、福利站 UI、破壳/死亡/继承纪念点位 |
| 阶段四后 | 插屏（限频）、Banner（福利站） |
| 阶段五（内容测试） | 频次与 eCPM 调优、留存影响评估 |
| 阶段六（后台统计） | 平台政策接入、数据看板 |

## 9. 平台政策与运营增益（2026）

- **流量主门槛**：累计独立用户 UV ≥ 500 即可申请开通（较此前 1000 下调）。
- **IAA 专项激励**：2026 年微信对小游戏 IAA 有注册激励与长线激励政策，通过买量/视频号渠道注册且活跃达标的用户，可按广告流水一定比例获得激励（需以官方最新政策为准）。
- **视频号场景**：视频号渠道（加热/短视频 CPS/直播 CPS）转化注册且游戏内活跃 > 3 分钟的用户，可按方案获得加热金激励（40%×30 天 或 35%×180 天两档，2026-11 起活跃门槛由 5 分钟降至 3 分钟）。
- **合规底线**：不得诱导欺骗增加时长、不得涉赌涉黄欺诈、遵守用户运营与内容规范，否则平台有权收回激励。

> 政策细节会变动，正式接入前以「微信公众平台 - 流量主」与官方公告为准。

## 10. 风险与对策汇总

| 等级 | 风险 | 对策 |
|---|---|---|
| 🔴 高 | 广告 bypass 核心玩法，摧毁养成内核 | 第 1 章红线硬约束，商品审查找除 |
| 🔴 高 | 过度广告导致留存下滑 | 激励为主、插屏限频、新用户保护、关键节点免打扰 |
| 🔴 高 | 审核拒绝（诱导/未成年/内容） | 自愿观看、平台默认过滤、合规自查清单 |
| 🟡 中 | 无货币导致奖励感薄弱 | 用纪念影片/装扮/碎片强化情感反馈，动画音效补足 |
| 🟡 中 | 平台政策变动影响收益模型 | 收益模型不依赖单一激励，收入结构留弹性 |
| 🟢 低 | 浏览器预览无真实广告 | mock 层发奖，保证 Demo 验证路径完整 |

## 11. 待确认事项

1. 广告店入口解锁时机：成体解锁（当前方案）还是首次领养即可见？
2. 激励视频每日上限：8 次是否合适（可下调至 5 次更克制）？
3. 纪念影片类奖励的实现形式：本地生成图片序列，还是阶段六接入服务端合成视频？
4. 是否接受「看片获得图鉴碎片」——虽不影响平衡，但会略微加速收集，是否保留？
5. 插屏是否要在 Demo 阶段（阶段四）就接入，还是等留存数据验证后再加？
6. 视频号 CPS / 买量场景激励，是否在阶段六纳入运营计划？
7. 挑蛋刷新已落地且不限次数：是否观察一段真实数据后再决定是否加次数上限？
