# CyberPet

拟真史前恐龙主题微信小游戏（拓麻歌子式电子宠物养成）。

## 技术栈

- 微信小游戏（Canvas 2D + 原生 JavaScript，无第三方运行时依赖）
- 平台适配层：同一套源码在微信小游戏（wx API）与浏览器预览中均可运行
- 微信开发者工具（编译/真机调试）；本地无工具时可用浏览器预览
- Git + GitHub（HTTPS + PAT）

## 目录结构

```
game.js                 微信小游戏入口
game.json / project.config.json   小游戏配置
index.html              浏览器预览入口（无需开发者工具）
src/
  config.js             物种/数值配置（口径 = GDD v0.6）
  platform.js           wx / 浏览器平台适配
  store.js              存档、结算、孵化、衰减、死亡、继承、纪念相册
  render.js             Canvas 矢量绘制（蛋/恐龙/状态条/弹层，零图片资源）
  input.js              触摸命中检测
  main.js               主循环与场景管理（领养/照顾/死亡 + 弹层）
tools/
  test-store.js         数据层单测（node tools/test-store.js）
  screenshot.js         Playwright 渲染截图验证
```

## 本地运行

**浏览器预览（快速）**
```bash
python -m http.server 8901
# 打开 http://127.0.0.1:8901/index.html
```
右上角「调试」面板可加速时间、注入后代、强制死亡、重置存档，便于验证数十天的生命周期。

**微信开发者工具**
以本项目根目录导入，编译类型选择「小游戏」，appid 可用测试号（当前配置为 `touristappid`）。

## 阶段二 Demo 已实现范围

- 随机蛋（纯视觉辨识，零文字提示）→ 按物种计时孵化 → 破壳揭晓种类与性别
- 三种恐龙矢量造型（霸王龙 / 蛇颈龙 / 三角龙）+ 体征/性别差异
- 5 项状态衰减、离线保护期、病变死亡与自然衰老（寿命按个体在物种范围内浮动）
- 单线继承：有后代则继承，无后代补偿随机蛋
- 全阶段纪念相册（破壳与阶段升级自动留影）
- 互动：喂食（按食性）、清洁、抚摸、休息、药草治疗

**暂未实现（阶段三）**：繁育与孕期、产后虚弱护理、物种专属小游戏、好友互动、匹配大厅。

**待验证**：当前环境未安装微信开发者工具，真机帧率与触摸手感尚未实测，建议在开发者工具中导入跑一遍。
